# Stratégie

Convictions de l'entreprise sur son marché et sur la bonne façon de travailler. Elles guident les arbitrages : un projet qui en contredit une doit le justifier.

## Convictions

- **Les clients achètent une preuve avant un engagement.** Une offre d'entrée courte et à prix fixe convertit mieux qu'une proposition longue, d'où le projet [Lancement de l'offre Diagnostic](../../1-Projects/lancement-offre-diagnostic/README.md).
- **La spécialisation sectorielle se paie.** Un client accepte un tarif plus élevé quand l'équipe connaît déjà son métier.
- **Le savoir de l'entreprise doit survivre aux départs.** Chaque mission laisse une trace réutilisable dans ce wiki.
