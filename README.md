## Comment s'en servir

Ouvrez ce dossier avec votre assistant IA (Claude, Claude Code, OpenCode, Pi) ou avec Obsidian, puis parlez-lui normalement :

- « Ajoute cet article au wiki : https://… »
- « Voici le transcript de la réunion de ce matin, fais-en le compte rendu »
- « Comment se passe l'arrivée d'un nouveau collaborateur ? »
- « Rédige une note de cadrage pour le projet X », « Prépare un deck pour le comité de lundi »

L'assistant range l'information au bon endroit, relie les pages entre elles et vous demande votre accord avant de modifier ce qui existe. Le guide de [prise en main](INSTALL.md) détaille chaque outil.

Le wiki est rangé en quatre dossiers : les **projets** en cours, le **fonctionnement** de l'entreprise, suivi en continu, les **ressources** de référence et les **archives**. Cette page en est le sommaire.
