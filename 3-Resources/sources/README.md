# Sources

Captures brutes et immuables : articles web, emails, transcripts, documents externes. Elles gardent leur langue et leur forme d'origine, l'analyse vit dans les pages du wiki qui les citent.

Les fichiers sont datés (`YYYY-MM-DD-slug.md`) et versés par la skill "ingest" ou, pour les réunions, par la skill "add-meeting-notes" dans `transcripts/`.
